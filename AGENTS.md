# Instruções para agentes

Antes de qualquer alteração neste repositório, leia e siga:

1. [docs/governance/agent-policy.md](docs/governance/agent-policy.md): regras obrigatórias, inclusive a
   de autoria (nenhuma atribuição automática a ferramentas de inteligência artificial).
2. [docs/governance/github-workflow.md](docs/governance/github-workflow.md): issue → branch → PR para
   `dev` → `homolog` → `main`.
3. [docs/STATUS.md](docs/STATUS.md): situação atual e pendências.
4. [CONTRIBUTING.md](CONTRIBUTING.md): comandos de teste e abertura de PR.
